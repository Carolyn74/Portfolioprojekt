# Analyse von Umsatzentwicklung, Rabattstrategien und Profitabilität

## Projektüberblick

Ziel dieses Projekts ist es, anhand des Superstore-Datensatzes den Zusammenhang zwischen Umsatz, Rabatten und Profitabilität zu analysieren. Im Mittelpunkt steht die Entwicklung von Umsatz und Profitabilität zwischen 2014 und 2017 sowie der Einfluss von Rabattstrategien auf die Ertragslage des Unternehmens.
